# Agent Session Flags

Short-lived actionable items that need to surface at the top of the next agent session. Cleared when resolved.

**Format:** one line per flag, starts with `- YYYY-MM-DD` followed by the action.

**Discipline:** write flags when ending a session with non-obvious follow-ups. Clear them when addressed. Abandon them with a note in that day's memory log if no longer relevant.
